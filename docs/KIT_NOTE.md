# Kit / Corpus Note

The uploaded `participant-kit-all-themes.zip` was inspected. Its included public kit is for other hackathon themes and does not provide the official Theme 4 corpus needed for the Streaming Live RAG benchmark.

This repository therefore contains a small **clearly-labelled local demonstration corpus**. It is not presented as the official Samsung benchmark corpus.

When the official Theme 4 corpus/test files are available, replace `data/sample_corpus.jsonl` (or point `CORPUS_PATH` at the official JSONL) and run the benchmark again.
